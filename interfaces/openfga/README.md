# charmlibs.interfaces.openfga

The `openfga` interface library.

To install, add `charmlibs-interfaces-openfga` to your Python dependencies. Then in your Python code, import as:

```py
from charmlibs.interfaces import openfga
```

See the [reference documentation](https://canonical.com/juju/docs/charmlibs/reference/charmlibs/interfaces/openfga) for more.
