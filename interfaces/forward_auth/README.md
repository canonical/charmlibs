# charmlibs.interfaces.forward_auth

The `forward-auth` interface library.

To install, add `charmlibs-interfaces-forward-auth` to your Python dependencies. Then in your Python code, import as:

```py
from charmlibs.interfaces import forward_auth
```

See the [reference documentation](https://canonical.com/juju/docs/charmlibs/reference/charmlibs/interfaces/forward-auth) for more.
