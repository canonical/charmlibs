# charmlibs.interfaces.vault_kv

The `vault-kv` interface library.

To install, add `charmlibs-interfaces-vault-kv` to your Python dependencies. Then in your Python code, import as:

```py
from charmlibs.interfaces import vault_kv
```

See the [reference documentation](https://canonical.com/juju/docs/charmlibs/reference/charmlibs/interfaces/vault-kv) for more.
