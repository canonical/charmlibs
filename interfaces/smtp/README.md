# charmlibs.interfaces.smtp

The `smtp` interface library.

To install, add `charmlibs-interfaces-smtp` to your Python dependencies. Then in your Python code, import as:

```py
from charmlibs.interfaces import smtp
```

See the [reference documentation](https://canonical.com/juju/docs/charmlibs/reference/charmlibs/interfaces/smtp) for more.
