# charmlibs.interfaces.smtp_testing

The `smtp` testing library. Charms that use `smtp` should use this library in their state-transition tests.

To install, add `charmlibs-interfaces-smtp-testing` to your Python dependencies. Then in your Python code, import as:

```py
from charmlibs.interfaces import smtp_testing
```

See the [library reference documentation](https://canonical.com/juju/docs/charmlibs/reference/charmlibs/interfaces/smtp) for more.
